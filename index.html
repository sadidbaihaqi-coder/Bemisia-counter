Catatan metode

Fitur deteksi ini bukan model AI dan tidak mengidentifikasi spesies. Algoritme mencari komponen kecil yang tampak terang/kurang jenuh pada foto. Pantulan, residu perekat, dan serangga lain dapat ikut terdeteksi; beberapa Bemisia juga dapat terlewat. Hitungan akhir harus dikoreksi manual.

Prototipe untuk pengujian alur kerja. Jika pemilih foto tidak terbuka saat file dibuka di pratinjau Files, simpan file lalu buka melalui Safari. Jangan gunakan hitungan manual ini sebagai hasil AI atau data tervalidasi tanpa pemeriksaan.
